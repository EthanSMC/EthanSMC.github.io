# 写作阅读交互优化设计

## 目标

让读者在长文中始终知道三件事：自己正在读哪一节、全文还剩多少、如何快速跳到另一节或返回写作首页。交互保持安静，不把个人博客改造成知识库，也不让导航与正文争夺注意力。

本轮只完成本地实现与验收，不部署。视觉方向采用用户已选择的「安静的编辑部」。沿用现有蓝色、纸张、手写标题与系统字体，不更换品牌配色、字体或内容资产。

## 设计原则

- 正文永远是第一视觉层级，阅读控件只在需要时出现。
- 长文获得完整导航；短随记不增加多余界面。
- 桌面利用页边空间，移动端把次要信息收进底部目录。
- 所有核心路径使用原生链接、按钮和对话框语义，支持键盘、触摸与减弱动态模式。
- 无 JavaScript 时正文、标题、相邻文章与返回写作仍完整可用。

## 启用条件

文章页通过独立的 `data-reader-minutes` 提供阅读时长，避免与元信息本地化使用的 `data-reading-minutes` 冲突；仅在满足以下任一条件时进入完整导航状态：

- 正文包含至少 3 个 `h2`/`h3` 标题；或
- 预计阅读时间不少于 5 分钟。

不满足条件的短随记只保留轻量阅读进度，不显示目录按钮和桌面页边目录。专辑页与写作索引不启用文章阅读导航。

## 页面结构

### 写作入口一致性

首页与写作索引中的主要内容卡片都使用可预期的原生链接：专辑封面、独立文章整卡和碎碎念整卡均可点击。卡片内不叠加 JavaScript 跳转，也不创建嵌套链接；标题、摘要、元信息和标签共同位于同一个 `<a>` 点击目标中。桌面提供克制的位移或颜色反馈，键盘显示统一焦点环，触摸设备保持整卡点击但不依赖悬停效果。

### 阅读工具条

文章标题区之后新增语义化阅读工具条。它在滚过文章标题后停靠在全局站点导航下方，包含：

- 返回写作首页的原生链接；
- 当前阅读章节，尚未进入第一个章节时显示文章标题；
- 百分比阅读进度，使用制表数字避免宽度跳动；
- 有目录时显示“目录”按钮，并通过 `aria-expanded` 表达开合状态。

工具条下缘是一条 3px 阅读进度线。进度以正文顶部到正文底部为计算区间，使用 `transform: scaleX()` 更新，避免触发布局重排。工具条不使用大阴影或玻璃拟态；只用现有纸张色、细边线和蓝色状态色。

### 桌面页边目录

在宽度足以容纳正文和页边信息时，目录显示在正文左侧页边，使用 `position: sticky` 随阅读停靠。正文仍维持舒适行宽，不因目录被压窄。

目录只列 `h2` 和 `h3`：`h2` 为主层级，`h3` 缩进但不增加额外装饰。当前章节通过蓝色文字、较高字重和 `aria-current="location"` 表示，不依赖颜色作为唯一提示。目录过长时在视口内滚动，不覆盖页尾导航。

### 移动端目录

窄屏不保留侧栏。点击工具条中的“目录”后，使用原生 `<dialog>` 打开底部目录：

- 标题为“本文目录”，右侧提供明确关闭按钮；
- 点击章节后关闭对话框并跳转；
- `Escape`、点击遮罩和关闭按钮都能退出；
- 触控目标不小于 44×44px，并考虑底部安全区；
- 打开与关闭使用 220–280ms 的减速过渡，减弱动态模式下立即切换。

## 章节与 URL 行为

现有 `blog.js` 继续为缺少 ID 的标题生成稳定 ID，并为重复标题追加序号，避免目录链接冲突。目录链接使用真实 `href="#heading-id"`，即使增强脚本部分失败，浏览器仍能完成跳转。

点击目录项后保留 URL hash。标题使用足够的 `scroll-margin-top`，避免被全局导航和阅读工具条遮挡。滚动监听使用 `IntersectionObserver` 更新当前章节；阅读进度使用被 `requestAnimationFrame` 合并的被动滚动监听。

## 视觉与排版

- 正文最大行宽从固定像素收敛到约 `68ch`，长文正文保持至少 `1rem`，桌面略增至约 `1.08rem`。
- 正文行高控制在约 `1.82–1.9`，段落间距形成稳定的 4px 基础节奏。
- 标题继续使用现有手写字体栈，字距不低于 `-0.04em`；正文不引入新字体。
- `h2` 与 `h3` 的间距进一步区分章节和小节；焦点状态使用统一 3px 蓝色外轮廓。
- 图片、代码块和表格保持在正文宽度内；横向内容可滚动且不造成页面级溢出。

## 响应式规则

- 小于约 720px：紧凑工具条、隐藏当前章节的次要文本、使用底部目录。
- 约 720–1239px：显示完整工具条，目录仍使用底部对话框，避免挤压正文。
- 约 1240px 以上：显示完整工具条和桌面页边目录；移动目录按钮保留为键盘/触摸备用入口或在页边目录可用时隐藏。
- 200% 缩放时回落到单栏与对话框目录，不产生水平溢出。

## 多语言与文案

新增的“目录”“本文目录”“关闭目录”“阅读进度”“返回写作”和当前章节占位文案进入现有中、日、英 `i18n.js` 字典。文章正文不翻译，继续遵循现有原文提示规则。

## 错误与降级

- 无标题：不显示目录，进度与返回路径仍可用。
- 重复标题：生成唯一 ID，目录项分别可达。
- `IntersectionObserver` 不可用：使用当前位置最近的标题作为退化计算；若脚本完全失败，原生锚点仍可用。
- `<dialog>` 不可用：使用 `open` 属性和既有样式退化为可关闭的固定面板。
- 页面高度不足一个视口：进度直接按正文区间夹紧到 0–100%，不出现 `NaN`。

## 测试与验收

自动化回归覆盖：

- 长文生成唯一目录链接，短文不显示目录；
- 阅读工具条拥有正确语义、标签和 44px 触控目标；
- 滚动后进度增加且当前章节同步更新；
- 点击桌面和移动目录项都到达目标标题，移动对话框随后关闭；
- `Escape`、遮罩和关闭按钮都能关闭目录；
- 390px、820px、1440px 视口无水平溢出；
- 减弱动态模式下工具条和目录过渡时长接近零；
- 中、日、英界面文案完整。

本地视觉验收覆盖桌面、平板、手机以及减弱动态模式。检查默认、停靠、当前章节、目录打开、键盘焦点、文章结尾和短随记状态。验收完成后只提供本地地址与截图，不执行预览或正式部署。

## 不在本轮范围

- 不改写文章内容或 Markdown 数据结构；
- 不增加搜索、收藏、分享、评论或账号系统；
- 不重做写作首页和专辑视觉系统；
- 不引入前端框架、动画库、字体或图标依赖；
- 不部署到 Vercel，也不变更正式域名。
